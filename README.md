# Player Game Tracker

A C# console application that tracks a player's game library, including hours played, ratings, and completion status.

---

## Features
- Collects player username and level
- Allows adding multiple games with:
  - Title
  - Genre
  - Hours played
  - Rating (1-10)
  - Completion status
- Calculates total hours played
- Displays player info and game library

---

## How to Run
1. Open in Visual Studio or your preferred C# IDE.
2. Build the project.
3. Run the program.
4. Follow prompts to enter player info and games.
5. The program will display a summary of the player and their game library.
